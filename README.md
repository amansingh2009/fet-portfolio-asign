# Personal Portfolio Website

I made this personal portfolio website for my Front End Technology subject. It
shares information about me, my skills, projects, education, certifications,
achievements, and contact details.

## Website sections

- Header with my name and a navigation bar
- Home, About, Skills, Projects, and Contact sections
- A Menu with Education, Certifications, and Achievements
- Project details and technical skills
- Email and social media links in the footer
- A layout that adjusts for smaller screens

## Technologies used

- **HTML** for the page structure and content
- **CSS** for the design and responsive layout
- **JavaScript** for the mobile navigation and Menu dropdown

## How to open it

Open `index.html` in a web browser. No extra software or packages are needed.

An internet connection is used to load the fonts. If they do not load, backup
fonts are used.

## Project files

- `index.html` — the page content
- `styles.css` — the page design and layout
- `script.js` — the navigation menus
- `README.md` — information about the project

## Personalizing the page

The name, email, social links, education, certifications, achievements, and
project details are examples. Change them in `index.html` to use your own
information.
